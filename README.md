# Hi there 👋 I'm Prabhroop Singh  

🎓 M.Eng in Electrical & Computer Engineering  
📍 University of Alberta 

## 🚀 About Me

I am a graduate researcher working at the intersection of **Machine Learning, Graph Neural Networks and decision-focused optimization**.  

My work spans:
- 🧠 Weakly supervised histopathology (MIL + CLAM attention + GNNs)  
- 🦴 3D pose optimization pipelines integrated with PyAutoscoper  
- 🚦 Graph-based traffic forecasting for urban transportation networks  
- ⚡ RF filter design automation using HFSS + ML  
- 📈 Decision-Focused Learning for risk-aware energy portfolio optimization  

I enjoy building **end-to-end pipelines** — from raw data and simulation to deployment and optimization.
